Ingat Kembali Konsep Fungsi Kuadrat

Bentuk umum, koefisien, diskriminan, dan langkah menggambar grafik

Bentuk Umum

y = ax² + bx + c

di mana a ≠ 0, a, b, c ∈ ℝ. Grafiknya berbentuk parabola.

Pengaruh Nilai a

  • a > 0: parabola terbuka ke atas (minimum)
  • a < 0: parabola terbuka ke bawah (maksimum)
  • Semakin besar |a|, parabola semakin sempit

Pengaruh Nilai b

  • b = 0: sumbu simetri adalah sumbu y
  • b > 0: puncak bergeser ke kiri
  • b < 0: puncak bergeser ke kanan

Pengaruh Nilai c

  • c > 0: memotong sumbu y di atas
  • c = 0: melalui titik (0,0)
  • c < 0: memotong sumbu y di bawah

Diskriminan (D)

D = b² − 4ac
  • D > 0: akar real berbeda (2 titik potong sumbu x)
  • D = 0: akar real kembar (1 titik potong)
  • D < 0: akar imajiner (tidak memotong)

Langkah-Langkah Menggambar Grafik Fungsi Kuadrat

1

Titik Potong Sumbu x

Selesaikan persamaan ax² + bx + c = 0

x = (−b ± √D) / 2a
2

Titik Potong Sumbu y

Substitusi x = 0 ke persamaan

y = c
3

Titik Puncak

Absis dan ordinat titik puncak:

xp = −b/2a, yp = −D/4a
4

Hubungkan Titik

Hubungkan semua titik dengan kurva mulus membentuk parabola. Gunakan titik cermin bila perlu.

Yang Telah Kita Pelajari

  • Bentuk umum fungsi kuadrat: y = ax² + bx + c
  • Pengaruh nilai a, b, c terhadap grafik parabola
  • Rumus diskriminan D = b² − 4ac
  • Langkah menggambar: titik potong x, y, dan puncak
  • Menentukan persamaan dari karakteristik grafik

Tips Penting

  • Cek tanda a: menentukan arah parabola
  • Nilai c = titik potong sumbu y
  • Tanda b bergeser berlawanan arah puncak
  • D > 0: 2 titik potong; D = 0: 1 titik; D < 0: tidak ada
  • Selalu hitung D terlebih dahulu sebelum mencari akar
