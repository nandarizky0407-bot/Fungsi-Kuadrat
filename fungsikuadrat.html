Mencari Akar-akar Kuadrat

Tiga metode utama — pilih dan pelajari

📌 Metode Faktorisasi

Memfaktorkan persamaan menjadi bentuk (x - x₁)(x - x₂) = 0. Akar-akarnya langsung terlihat.

x2 + bx + c = (x + p)(x + q) = 0

Syarat: p + q = b dan p × q = c

Contoh:

x2 − 5x + 6 = 0
  1. Cari dua bilangan yang hasil kalinya 6 dan jumlahnya −5 → −2 dan −3.
  2. Tulis dalam bentuk faktor: (x − 2)(x − 3) = 0
  3. Setiap faktor = 0: x − 2 = 0 atau x − 3 = 0
  4. Sehingga: x₁ = 2 dan x₂ = 3
✓ Kelebihan: Cepat untuk persamaan yang akarnya bilangan bulat sederhana.

📌 Metode Kuadrat Sempurna

Mengubah persamaan ke bentuk (x + p)² = q dengan melengkapi kuadrat sempurna.

x2 + bx + c = (x + b/2)2 − (b/2)2 + c

Contoh:

x2 + 6x + 5 = 0
  1. Pindahkan konstanta: x² + 6x = −5
  2. Tambahkan (b/2)² = (6/2)² = 9 ke kedua sisi: x² + 6x + 9 = −5 + 9
  3. Bentuk kuadrat sempurna: (x + 3)² = 4
  4. Akar kedua sisi: x + 3 = ±√4 = ±2
  5. Sehingga: x₁ = −1 dan x₂ = −5
💡 Tip: Cocok ketika koefisien a = 1 dan b genap, sehingga b/2 bulat.

📌 Rumus ABC (Rumus Kuadrat)

Rumus universal yang selalu berhasil untuk semua persamaan kuadrat.

x1,2 = −b ± √(b2 − 4ac)
2a
Diskriminan D = b² − 4ac menentukan jenis akar:
  • D > 0 → dua akar real berbeda
  • D = 0 → satu akar real kembar
  • D < 0 → tidak ada akar real (akar imajiner)

Contoh:

2x2 − 7x + 3 = 0
  1. a = 2, b = −7, c = 3
  2. D = (−7)² − 4(2)(3) = 49 − 24 = 25
  3. x = (7 ± √25) / (2·2) = (7 ± 5) / 4
  4. x₁ = 12/4 = 3 dan x₂ = 2/4 = 1/2

Karakteristik Grafik Parabola

Peran a, diskriminan D, dan konstanta c

a

Pengaruh Nilai a

Mengatur arah dan kelengkungan parabola:

  • a > 0 → terbuka ke atas (minimum)
  • a < 0 → terbuka ke bawah (maksimum)
  • |a| besar → parabola sempit
  • |a| kecil → parabola melebar

Hijau: a>0 sempit • Merah: a>0 melebar • Kuning: a<0

D

Diskriminan D = b²−4ac

Menentukan posisi parabola terhadap sumbu x:

  • D > 0 → memotong sumbu x di 2 titik
  • D = 0 → menyinggung sumbu x (1 titik)
  • D < 0 → tidak memotong sumbu x

Hijau: D>0 • Kuning: D=0 • Merah: D<0

c

Pengaruh Nilai c

Menentukan titik potong dengan sumbu y:

  • Saat x = 0 → f(0) = c
  • c > 0 → potong sumbu y di atas
  • c = 0 → melalui titik asal (0,0)
  • c < 0 → potong sumbu y di bawah
  • Menggeser parabola secara vertikal

Geser naik: c besar → kecil

Titik Puncak Parabola

Rumus (xp, yp) — sumbu simetri dan nilai ekstrem

📍 Rumus Titik Puncak

Titik puncak (vertex) adalah titik ekstrem parabola — minimum jika a > 0, maksimum jika a < 0.

xp = −b
2a
yp = f(xp) = a·xp2 + b·xp + c
Atau gunakan rumus praktis:
yp = −D
4a  =  −(b2−4ac)
4a
Sumbu simetri: garis vertikal x = xp = −b/(2a). Parabola simetris terhadap garis ini.

🧮 Contoh Perhitungan

y = x2 − 6x + 8
  1. a = 1, b = −6, c = 8
  2. xp = −(−6) / (2·1) = 6/2 = 3
  3. yp = (3)² − 6(3) + 8 = 9 − 18 + 8 = −1
  4. Titik puncak: (3, −1)
  5. Sumbu simetri: x = 3
  6. Karena a = 1 > 0 → nilai minimum = −1

Menggambar Grafik Kuadrat

Lima langkah praktis + bantuan GeoGebra

📝 Lima Langkah Menggambar

  1. Tentukan arah parabola — lihat tanda a: ke atas (a>0) atau ke bawah (a<0).
  2. Cari titik potong sumbu y — hitung f(0) = c → titik (0, c).
  3. Cari titik potong sumbu x — selesaikan ax² + bx + c = 0 (gunakan faktorisasi/ABC). Bila D<0, parabola tidak memotong sumbu x.
  4. Hitung titik puncak — xp = −b/(2a), yp = f(xp). Ini sumbu simetri.
  5. Plot titik-titik di koordinat kartesius, lalu hubungkan dengan kurva mulus berbentuk parabola.
Tip Cepat: Tambahkan 1-2 titik simetris (misal di xp±1) untuk meningkatkan akurasi gambar.

🎨 Contoh: y = x² − 4x + 3

  1. a = 1 > 0 → parabola terbuka ke atas.
  2. Titik potong sumbu y: f(0) = 3 → (0, 3).
  3. Titik potong sumbu x: x² − 4x + 3 = (x−1)(x−3) = 0 → (1, 0) dan (3, 0).
  4. Titik puncak: xp = 4/2 = 2, yp = 4−8+3 = −1 → (2, −1).
  5. Plot (0,3), (1,0), (2,−1), (3,0), lalu simetris (4,3) — gambar parabola mulus.

Pengayaan: Teorema Vieta

Hubungan elegan antara akar dan koefisien

🔮 Apakah Teorema Vieta?

Teorema Vieta memberi hubungan langsung antara jumlah dan hasil kali akar dengan koefisien persamaan — tanpa perlu mencari akarnya terlebih dahulu!

Untuk ax2 + bx + c = 0 dengan akar x1 dan x2:
Σ

Jumlah Akar

x1 + x2 = −b
a

Hasil kali koefisien b berlawanan tanda dibagi a.

Contoh: x² − 5x + 6 = 0 → a=1, b=−5
x₁ + x₂ = −(−5)/1 = 5
Π

Hasil Kali Akar

x1 · x2 = c
a

Konstanta c dibagi koefisien a.

Contoh: x² − 5x + 6 = 0 → a=1, c=6
x₁ · x₂ = 6/1 = 6

⚡ Aplikasi Teorema Vieta

Sangat berguna untuk:

// MENYUSUN PERSAMAAN

Diketahui akar-akar x₁ dan x₂ → persamaan: x² − (x₁+x₂)x + (x₁·x₂) = 0

// TANDA AKAR

Jika D ≥ 0, tanda akar ditentukan oleh: −b/a (jumlah) dan c/a (hasil kali).

// SOAL CEPAT

Tanpa mencari akar, langsung hitung jumlah/hasil kali akar dari koefisien.

Contoh Soal: Persamaan 2x² + 5x − 3 = 0 memiliki akar x₁ dan x₂. Tentukan nilai x₁ + x₂ dan x₁ · x₂ tanpa mencari akarnya.
→ x₁ + x₂ = −5/2 = −2,5 dan x₁ · x₂ = −3/2 = −1,5
